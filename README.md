# MoodMusic: Recomendador de Playlist según el Estado de Ánimo

## Descripción del proyecto
MoodMusic es un proyecto de ciencia de datos que busca organizar canciones de acuerdo con diferentes estados de ánimo, con el propósito de facilitar la recomendación de playlists.

## Objetivo
Desarrollar un recomendador de canciones que permita seleccionar música de acuerdo con el estado de ánimo del usuario.

## Metodología
Se utiliza la metodología **OSEMN**, que comprende cinco etapas:

1. Obtain (obtener los datos).
2. Scrub (limpiar los datos).
3. Explore (explorar los datos).
4. Model (desarrollar el modelo).
5. iNterpret (interpretar los resultados).

## Estados de ánimo considerados
- Alegría
- Energía
- Tranquilidad
- Melancolía

## Estructura del repositorio
- `data/`: conjunto de datos del proyecto.
- `notebooks/`: cuadernos de análisis en Python.
- `src/`: código fuente.
- `dashboard/`: archivos del tablero de visualización.
